# 🧬 Skin Cancer Detection

An AI-powered web application for skin lesion screening using a deep learning model based on **ResNet50**.

The application provides a simple chat-style interface where users can upload a skin image or capture an image using their camera and receive an AI-based prediction with confidence scores.

> ⚠️ **Disclaimer:** This project is intended for educational, research, and preliminary screening purposes only. It is not a medical diagnostic tool.

---

## 🚀 Features

- 🧠 Deep Learning-based skin lesion classification
- 🧬 ResNet50 model
- 📷 Upload skin images
- 📹 Live camera capture
- 🤖 Chat-style AI interface
- 📊 Cancer probability score
- 📊 Non-Cancer confidence score
- 🔄 Reset prediction/chat
- 📱 Responsive user interface
- ⚡ Flask backend
- 🌐 Web-based application
- ☁️ Deployment-ready architecture
