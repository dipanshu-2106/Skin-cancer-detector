# Skin Cancer Detection using Deep Learning

An AI-powered web application that detects skin cancer from uploaded skin lesion images using a deep learning model based on ResNet50 architecture.

## Features

* Skin cancer image classification
* Real-time prediction system
* Image upload functionality
* Deep Learning model integration
* Flask-based web application
* Docker deployment support

## Technologies Used

* Python
* TensorFlow
* Keras
* ResNet50
* Flask
* Docker

## Dataset

* ISIC / HAM10000 Skin Lesion Dataset

## Model Performance

* Achieved approximately 90%+ prediction accuracy using transfer learning and image preprocessing techniques.
